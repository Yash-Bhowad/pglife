# PG Life – Student Accommodation Web App

This is the **PG Life** project developed as part of the Internshala Web Development course.  
It is a functional PHP + MySQL web application for showcasing PGs, with login/signup, filters, and property details.

---

## 🚀 Features
- User login & signup  
- Search and filter PG properties  
- Detailed property view  
- Wishlist / favorites (optional)  
- Fully responsive UI  
- PHP + MySQL backend  

---

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, Bootstrap, JavaScript  
- **Backend:** PHP  
- **Database:** MySQL  
- **Version Control:** Git & GitHub  

---

## 📂 Recommended Folder Structure
/css
/js

index.php

---

## ⚙️ How to Run
1. Clone the repository  
2. Import MySQL database  
3. Configure database connection  
4. Run using XAMPP / WAMP
